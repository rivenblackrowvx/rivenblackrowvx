## 👨‍💻 Sobre mí

Perfil técnico orientado a **ciberseguridad** y **DevOps**. Me enfoco en proteger redes e infraestructuras cloud, automatizar tareas con código y construir proyectos que integran **APIs, datos y machine learning**.

- 🔒 **Ciberseguridad**: hardening de sistemas Linux/Windows, pentesting y evaluación de vulnerabilidades.
- ⚙️ **DevOps**: automatización, contenedores y despliegue de entornos reproducibles.
- 🌐 **Redes**: firewalls, routing, switching y ACLs (Fortigate, Cisco).
- ☁️ **Cloud Security**: AWS (VPC, IAM, EC2).
- 📊 **Datos y algoritmia**: ingesta de APIs, análisis de datos y modelos de ML.
